# ADR-журнал

Этот журнал нужен для фиксации проектных решений и трассировки между кодом, Linear и Figma.

## Правила

1. Каждое значимое решение фиксируется отдельным ADR-файлом.
2. В ADR обязательно указываются ссылки на Linear и Figma (если применимо).
3. Если решение изменено, старый ADR получает статус `superseded`.
