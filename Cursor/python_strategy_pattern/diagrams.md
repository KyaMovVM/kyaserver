# Диаграммы паттерна Стратегия

## 🔴 ПРОБЛЕМА: Наследование

```
                        ┌─────────────────┐
                        │      Duck       │
                        │─────────────────│
                        │ + quack()       │ ← Все утки крякают?
                        │ + swim()        │ ← OK
                        │ + fly()         │ ← ❌ Все утки летают?!
                        │ + display()*    │
                        └────────┬────────┘
                                 │
           ┌─────────────────────┼─────────────────────┐
           │                     │                     │
           ▼                     ▼                     ▼
    ┌─────────────┐      ┌─────────────┐      ┌─────────────┐
    │ MallardDuck │      │ RubberDuck  │      │  DecoyDuck  │
    │─────────────│      │─────────────│      │─────────────│
    │ + display() │      │ + display() │      │ + display() │
    │             │      │ + quack()   │←пищит│ + quack()   │←молчит
    │             │      │ + fly()     │←❌    │ + fly()     │←❌
    └─────────────┘      └─────────────┘      └─────────────┘
         OK!              Переопределяем       Переопределяем
                          2 метода!            2 метода!
```

### Проблемы:

1. **Дублирование**: `fly() { }` копируется в RubberDuck и DecoyDuck
2. **Жёсткая связь**: Поведение "зашито" в иерархию классов
3. **Нет гибкости**: Нельзя менять поведение во время выполнения

## 🧩 Принципы проектирования

```
┌─────────────────────────────────────────────────────────────────────┐
│                    ПРИНЦИПЫ ПРОЕКТИРОВАНИЯ                          │
├─────────────────────────────────────────────────────────────────────┤
│                                                                     │
│  1️⃣ ИНКАПСУЛИРУЙТЕ ТО, ЧТО ИЗМЕНЯЕТСЯ                               │
│     ────────────────────────────────                                │
│     • fly() и quack() — изменяются → выносим в отдельные классы     │
│     • swim() — не изменяется → оставляем в Duck                     │
│                                                                     │
├─────────────────────────────────────────────────────────────────────┤
│                                                                     │
│  2️⃣ ПРОГРАММИРУЙТЕ НА УРОВНЕ ИНТЕРФЕЙСА                             │
│     ────────────────────────────────────                            │
│     • Объявляем: FlyBehavior flyBehavior (интерфейс!)               │
│     • Присваиваем: flyBehavior = new FlyWithWings() (реализация)    │
│     • Можем заменить на любую другую реализацию!                    │
│                                                                     │
├─────────────────────────────────────────────────────────────────────┤
│                                                                     │
│  3️⃣ КОМПОЗИЦИЯ ЛУЧШЕ НАСЛЕДОВАНИЯ                                   │
│     ────────────────────────────────                                │
│     • IS-A (наследование): RubberDuck IS-A Duck ✗ жёстко            │
│     • HAS-A (композиция): Duck HAS-A FlyBehavior ✓ гибко            │
│                                                                     │
└─────────────────────────────────────────────────────────────────────┘
```

## 📝 Формула паттерна

```
┌─────────────────────────────────────────────────────────────────────┐
│                                                                     │
│    ПАТТЕРН СТРАТЕГИЯ определяет семейство алгоритмов,               │
│    инкапсулирует каждый из них и делает их взаимозаменяемыми.       │
│                                                                     │
│    Стратегия позволяет изменять алгоритмы независимо                │
│    от клиентов, которые ими пользуются.                             │
│                                                                     │
└─────────────────────────────────────────────────────────────────────┘

       КОНТЕКСТ (Duck)                    СТРАТЕГИИ (Behaviors)
    ┌─────────────────────┐            ┌─────────────────────┐
    │                     │            │   «interface»       │
    │   strategy ─────────┼──────────► │   Strategy          │
    │                     │            │   ───────────       │
    │   execute() {       │            │   + algorithm()     │
    │     strategy.       │            └──────────┬──────────┘
    │       algorithm()   │                       │
    │   }                 │              ┌────────┼────────┐
    │                     │              ▼        ▼        ▼
    └─────────────────────┘           Algo1    Algo2    Algo3
```
