# Алгоритмы

## Что такое алгоритмы?

Алгоритмом называется набор инструкций для выполнения некоторой задачи.

Необходимо знать базовую алгебру. Например, возьмём следующую функцию: \(f(x) = x × 2\).

## Бинарный поиск

Бинарный поиск — алгоритм поиска по отсортированному списку (почему нужна сортировка — ниже). Если искомый элемент есть в списке, возвращается его позиция, иначе — null.

### Пример

Сыграем в простую игру: я загадал число от 1 до 100. Предположим, вы начинаете перебирать все варианты подряд: 1, 2, 3, 4 … Это пример простого поиска.

**Более эффективный поиск:**
- Начнём с 50
- Исключили половину чисел

*При бинарном поиске каждый раз исключается половина чисел*

Предположим, вы ищете слово в словаре с 240 000 словами. Бинарный поиск выполняется за log₂n шагов.

## Логарифмы

Возможно, вы уже забыли, что такое логарифм, но наверняка помните, что такое возведение в степень. log₁₀100 по сути означает, сколько раз нужно перемножить 10, чтобы получить 100. Правильный ответ — 2: 10 × 10. Итак, log₁₀100 = 2. Логарифм по смыслу противоположен возведению в степень.

## O-большое

O-большое — асимптотическая оценка времени выполнения алгоритма в зависимости от размера входных данных.

**Асимптотический анализ** — метод оценки алгоритмов по поведению при росте размера входа. Изучает, как ведёт себя функция при стремлении аргумента к предельным значениям.

### Свойства O-большого

- **Рефлексивность:** для любой функции f(n) выполняется f(n) = O(f(n))
- **Транзитивность:** если f(n) = O(g(n)) и g(n) = O(h(n)), то f(n) = O(h(n))

### Правила

- C · o(f) = o(f)
- C · O(f) = O(f)
- o(C · f) = o(f)
- O(f) + O(f) = O(f)
- o(f) + O(f) = O(f)
- o(f) · O(f) = O(f)
- o(f) · o(f) = o(f)
- O(f) · O(f) = O(f)
- O(f) · o(f) = O(f)
- o(f) / O(f) = o(f)
- o(f) / o(f) = o(f)
- O(f) / O(f) = O(f)
- O(f) / o(f) = O(f)

### Алгоритм 1: O(n)

Рисуем n квадратов, по одному за раз. Операция — рисование одного квадрата. Для n квадратов выполняется n операций.

### Алгоритм 2: O(log n)

Складываем лист пополам. Операция — одно сложение. Одна операция создаёт сразу два прямоугольника. Сложите ещё раз — четыре. И ещё — восемь. k сложений → 2^k прямоугольников. Чтобы получить n прямоугольников, нужно log₂n операций.

## Массивы и связанные списки

### Гардероб в театре

Представьте, что вы пришли в театр и хотите оставить свои личные вещи в гардеробе. Для хранения вещей есть специальные ящики. В каждом ящике помещается один предмет. Вы хотите сдать на хранение две вещи, поэтому требуете выделить вам два ящика.

### Массивы

При использовании массива все элементы хранятся в памяти **непрерывно** — в соседних ячейках. Проблема: если нужно добавить ещё один элемент, а следующая ячейка уже занята, придётся искать новый свободный блок под весь массив и копировать данные.

### Связанные списки

Связанные списки решают проблему добавления новых элементов. В каждом элементе хранится адрес следующего — так набор произвольных ячеек памяти объединяется в цепочку.

По аналогии с игрой «Найди клад»: приходите по первому адресу, там указан следующий (123), идёте туда, там снова ссылка (847) и т. д. Добавить новый элемент просто: разместите его в любом свободном месте и сохраните его адрес в предыдущем элементе. Ничего перемещать в памяти не нужно.

Ещё один плюс: в кинотеатре сложно найти шесть соседних мест, но можно сесть по одному в разных рядах. С массивами аналогично — иногда есть место для 10 000 элементов, но не в одном смежном блоке. Со связанным списком можно использовать любые свободные ячейки памяти.
