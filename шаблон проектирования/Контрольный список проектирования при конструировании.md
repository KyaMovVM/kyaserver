# Контрольный список: проектирование при конструировании

Источник: Code Complete 2, раздел 5.2.7  
Ссылка: http://cc2e.com/0527

## Методики проектирования

- [ ] Выполнены несколько итераций проектирования, и выбрана лучшая попытка, а не первая.
- [ ] Декомпозиция системы выполнена несколькими способами для поиска наилучшего варианта.
- [ ] Для решения проблемы использованы и нисходящий, и восходящий подходы проектирования.
- [ ] Выполнено прототипирование сомнительных или плохо известных частей системы с созданием минимального объема кода, подлежащего выбрасыванию.
- [ ] Проведен формальный или неформальный обзор проекта другими разработчиками.
- [ ] Проектирование доведено до точки, где реализация кажется очевидной.
- [ ] Проект зафиксирован уместными способами: Wiki, электронная почта, плакаты, цифровые фотографии, UML, CRC-карточки или комментарии в коде.

## Цели проектирования

- [ ] Проект адекватно решает проблемы, определенные и отложенные на этапе разработки архитектуры.
- [ ] Проект разделен на уровни.
- [ ] Декомпозиция программы на подсистемы, пакеты и классы выполнена удовлетворительно.
- [ ] Декомпозиция классов на методы выполнена удовлетворительно.
- [ ] Достигнуто минимальное взаимодействие классов между собой.
- [ ] Классы и подсистемы спроектированы так, чтобы их можно было использовать повторно в других системах.
- [ ] Программа будет легкой в сопровождении.
- [ ] Проект полный, но минимальный; все его части действительно необходимы.
- [ ] Проект подразумевает использование только стандартных методик.
- [ ] Удалось избежать применения экзотических и трудных для понимания элементов.
- [ ] Проект в целом помогает минимизировать и несущественную, и существенную сложность.
