# Руководство для Cursor AI

Добро пожаловать в документацию проекта для работы с Cursor AI. Этот файл поможет AI-ассистенту лучше понимать структуру проекта, архитектуру и лучшие практики разработки.

## 📋 Обзор проекта

**KyaServer** — монорепозиторий, объединяющий несколько связанных проектов через Git submodules:

- **Main** (`main-project/`) — основное приложение (JavaScript/Node.js)
- **Main.wiki** (`wiki/`) — документация проекта в формате Markdown
- **docker-projects/** — набор Docker-контейнеров для разных сценариев использования

## 📝 Работа с Git Submodules

Проект использует Git submodules для управления связанными репозиториями.

### Обновление submodules

```bash
# Обновить все submodules до последней версии
git submodule update --remote

# Обновить конкретный submodule
cd main-project
git pull origin main
cd ..
git add main-project
git commit -m "Update main-project submodule"
```

### Внесение изменений в submodules

Изменения в submodules требуют отдельного коммита и push:

```bash
# Изменения в основном репозитории
git add .
git commit -m "Description"
git push

# Изменения в submodule
cd main-project
git add .
git commit -m "Description"
git push
cd ..
git add main-project
git commit -m "Update main-project reference"
git push
```

## 📚 Документация

### Структура wiki

Документация находится в директории `wiki/` (Git submodule):

- `Home.md` — главная страница вики
- `1-overview.md`, `2-build.md`, и т.д. — нумерованные разделы
- `idea-submodule.md` — руководство по работе с submodules
- `test-node.md` — документация по тестированию Node.js

### Ведение документации

1. **Создание новой статьи:**
   - Добавьте файл `.md` в директорию `wiki/`
   - Используйте понятные имена файлов (kebab-case)
   - Добавьте ссылку на новую статью в `Home.md` или соответствующем разделе

2. **Обновление существующей документации:**
   - Редактируйте файлы напрямую в `wiki/`
   - Используйте Markdown синтаксис
   - Коммитьте изменения в submodule отдельно

3. **Форматирование:**
   - Заголовки: `#`, `##`, `###`
   - Списки: `-` для маркированных, `1.` для нумерованных
   - Код: обратные кавычки `` ` `` для inline, тройные кавычки для блоков
   - Ссылки: `[текст](файл.md)` для внутренних ссылок

## 💡 Рекомендации для разработки

### Стиль кода

- Используйте ESLint/Prettier для форматирования
- Следуйте стандартам JavaScript (ES6+)
- Пишите понятные имена переменных и функций
- Добавляйте комментарии для сложной логики

### Работа с зависимостями

- Каждый проект имеет свой `package.json`
- Корневой `package.json` — только для тестов корневого уровня
- Не объединяйте зависимости разных проектов

### Работа с Cursor AI

- **Контекст:** Cursor AI имеет доступ ко всему проекту, включая submodules
- **Запросы:** Формулируйте четкие и конкретные задачи
- **Изменения:** Проверяйте предлагаемые изменения перед применением
- **Документация:** Обновляйте эту документацию при значительных изменениях архитектуры

## 🔍 Частые задачи

### Добавление нового Docker проекта

1. Создайте директорию в `docker-projects/`
2. Добавьте `Dockerfile` и `compose.yaml` при необходимости
3. Обновите основной `compose.yaml` если нужно
4. Добавьте документацию в `wiki/`

### Добавление нового теста

1. Создайте файл в `tests/__tests__/`
2. Используйте Jest для написания тестов
3. Запустите тесты: `npm test`

### Обновление зависимостей

1. Обновите `package.json` в соответствующем проекте
2. Запустите `npm install`
3. Проверьте, что все тесты проходят
4. Зафиксируйте изменения в `package-lock.json`

## 🇯🇵 Обучение японскому языку

Проект включает Agile систему для изучения японского языка:

- **Структура:** `JP/agile/` - спринты, прогресс, трекинг слов/кандзи
- **Интеграция с игрой:** JS Game (`main-project/Japanese game/`) интегрирована с системой обучения
- **Автоматизация:** Скрипты для добавления слов/кандзи и обновления прогресса
- **Цели:** 1500 слов, 300 кандзи, **JFT-Basic 200+** (основной языковой тест), SSW Skills Test
- **Ресурсы:** Genki I, Minna no Nihongo I, Duolingo, JS Game для иммерсивной практики

**При работе с японским языком:**
- Используйте скрипты в `JP/agile/scripts/` для автоматизации
- Обновляйте прогресс регулярно (еженедельно)
- Интегрируйте изученные слова в JS Game для практики
- Учитывайте ограниченное время (40+ часов работы в неделю)
