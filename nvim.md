# nvim

## Плагины

- **nvim-tree** — дерево файлов
- **molten-nvim** — выполнение Python кода (Jupyter)
- **image.nvim** — инлайн-картинки (matplotlib и т.д., требует Kitty)
- **tokyonight** — цветовая тема
- **lazy.nvim** — менеджер плагинов

## Терминал

Используй **Kitty** — поддерживает graphics protocol для отображения картинок в nvim.
Конфиг: `configs/kitty/kitty.conf` (тема tokyonight-night, zsh, прозрачность 95%).

## Зависимости

- `pynvim`, `jupyter_client`, `ipykernel` — Python-пакеты для molten
- `luarocks` + `magick` luarock — для image.nvim
- `libmagickwand-dev` — системная библиотека для magick
- Всё ставится через `configs/activate.sh`

## Vim в Codex CLI

Codex CLI умеет редактировать текст запроса в стиле Vim. В открытом Codex введи:

```text
/vim
```

Команда переключает Vim-режим только для текущей сессии. Чтобы включать его автоматически, добавь в `~/.codex/config.toml`:

```toml
[tui]
vim_mode_default = true
```

### Минимум для начала

| Клавиши | Действие |
|---------|----------|
| `i` | Перейти из normal mode в режим ввода |
| `Esc` | Вернуться в normal mode |
| `h` / `j` / `k` / `l` | Влево / вниз / вверх / вправо |
| `w` / `b` | На слово вперёд / назад |
| `0` / `$` | В начало / конец строки |
| `x` | Удалить символ |
| `dd` | Удалить строку |
| `D` | Удалить до конца строки |
| `cw` | Заменить слово |
| `u` | Отменить последнее изменение |
| `Ctrl + r` | Повторить отменённое изменение |
| `v` | Начать выделение |
| `y` | Скопировать выделенное |
| `p` | Вставить после курсора |

Обычный цикл работы: `i` → набрать запрос → `Esc` → поправить текст командами Vim → `Enter` → отправить запрос.

### Полезные команды Codex CLI

Введи `/`, чтобы открыть полный список команд текущей версии Codex.

| Команда | Действие |
|---------|----------|
| `/vim` | Включить или выключить Vim-режим ввода |
| `/status` | Показать модель, разрешения, рабочие каталоги и использование контекста |
| `/model` | Выбрать модель и доступный уровень reasoning |
| `/permissions` | Изменить разрешения Codex для текущей сессии |
| `/plan` | Перейти в режим составления плана |
| `/diff` | Показать staged, unstaged и untracked изменения Git |
| `/review` | Запустить ревью текущих изменений |
| `/mention путь` | Добавить файл или каталог в контекст запроса |
| `/compact` | Сжать длинную историю и освободить контекст |
| `/new` | Начать новый чат |
| `/resume` | Продолжить сохранённую сессию |
| `/copy` | Скопировать последний завершённый ответ |
| `/exit` | Выйти из Codex CLI |

Дополнительные сочетания:

- `@` — найти файл проекта и добавить его в запрос;
- `!команда` — выполнить локальную shell-команду;
- `Tab` во время работы Codex — поставить следующий запрос в очередь;
- `Enter` во время работы Codex — добавить инструкцию в текущий ход;
- `Ctrl + O` — скопировать последний завершённый ответ;
- `Ctrl + C` — выйти из Codex CLI.

Актуальный список: [официальная документация команд Codex](https://developers.openai.com/codex/cli/slash-commands).

## Хоткеи

### Общие

| Клавиши | Действие |
|---------|----------|
| `Space + e` | Открыть/закрыть дерево файлов |
| `Space + f` | Фокус на дерево файлов |
| `Ctrl + h/j/k/l` | Навигация между окнами |
| `Esc` | Убрать подсветку поиска |
| `V` + `J` / `K` | Сдвинуть строку вниз/вверх |

### nvim-tree

| Клавиши | Действие |
|---------|----------|
| `j` / `k` | Вверх/вниз по списку |
| `Enter` | Открыть файл / развернуть папку |
| `v` | Открыть в вертикальном сплите |
| `s` | Открыть в горизонтальном сплите |
| `t` | Открыть в новой вкладке |
| `a` | Создать файл/папку |
| `d` | Удалить |
| `r` | Переименовать |
| `x` | Вырезать |
| `c` | Копировать |
| `p` | Вставить |
| `Backspace` | Родительская папка |
| `W` | Свернуть все папки |
| `q` | Закрыть дерево |

### Molten (Python/Jupyter)

| Клавиши | Действие |
|---------|----------|
| `Space m i` | Запустить ядро Python |
| `Space m l` | Выполнить строку |
| `V` + выделить + `Space m` | Выполнить выделенный блок |
| `Space m r` | Перезапустить ячейку |
| `Space m o` | Показать вывод |
| `Space m h` | Скрыть вывод |
| `Space m d` | Удалить ячейку |

### Lazy.nvim

| Клавиши | Действие |
|---------|----------|
| `:Lazy` | Открыть менеджер плагинов |
| `q` | Закрыть окно плагинов |
