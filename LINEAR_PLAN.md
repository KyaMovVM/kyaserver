# План проекта KyaServer для Linear

## 🎯 Основные цели проекта

### 1. Разработка и поддержка монорепозитория
- Управление несколькими проектами через Git submodules
- Интеграция основного приложения (Main), документации (wiki) и Docker-проектов
- Поддержка структуры репозиториев на Gitea

### 2. Японская игра (Visual Novel)
- Разработка движка визуальной новеллы на JavaScript
- Интеграция системы обучения японскому языку
- Создание интерактивных диалогов и сцен

### 3. Система обучения японскому языку (Agile)
- Достижение цели: 1500 слов (N5-N4 + SSW ресторанный словарь)
- Изучение 300 кандзи (N5-N4)
- Подготовка к JFT-Basic 200+ (A2 уровень)
- Подготовка к SSW Skills Test (45 вопросов, 70 минут)

### 4. Docker и инфраструктура
- Настройка Docker Compose для локальной разработки
- Поддержка множественных контейнеров
- Оптимизация развертывания
